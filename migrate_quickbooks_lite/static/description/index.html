What this module does

The Lite edition imports the four pieces of master data that every QuickBooks migration starts with. Export CSV from QuickBooks, upload to Odoo, the wizard auto-detects your columns, you click Import. That is the entire workflow.

1 — Chart of Accounts
  • Up to 100 accounts per file
  • QuickBooks types mapped to Odoo account types (70+ mappings)
  • QBO and QuickBooks Desktop CSV formats both supported
  • Auto-generates account codes when QuickBooks did not ship them
2 — Customers
  • Up to 100 customers per file
  • Name, email, phone, full billing address
  • Country and state auto-looked-up against Odoo masters
  • Payment terms matched by name (Net 30, Due on receipt, etc.)
3 — Vendors
  • Up to 100 vendors per file
  • 1099 tracking flag preserved as a partner note (US)
  • Tax ID / EIN / VAT carried over
  • Vendor payment terms mapped
4 — Items / Products
  • Up to 100 products per file
  • Service, Inventory, and Non-Inventory item types handled
  • Sales price and unit cost preserved
  • Income and expense accounts linked from your imported chart

How to use it

1 Install this module. A new "Migrate from QuickBooks" app appears in the top bar.
2 Export CSV from QuickBooks. Every list page in QuickBooks Online and Desktop has an "Export to Excel" option. Save the file as CSV.
3 Run the 4 importers in order. Chart of Accounts first (so products can reference accounts), then Customers, then Vendors, then Items.
4 Review the import log. The wizard reports created / updated / skipped counts and any row-level issues with line numbers.

What gets handled correctly

  • QBO and QBD CSV formats — auto-detects column variants like "Account" vs "Name", "Type" vs "Account Type"
  • Encoding sniffing — UTF-8 (QBO default), cp1252 (QBD Windows), latin-1 fallback
  • Delimiter sniffing — comma, tab, or semicolon
  • Junk title rows — QuickBooks exports often prepend metadata; the parser finds the real header automatically
  • QuickBooks type mapping — 70+ entries covering both common names ("Bank") and detail types ("Sales of Product Income")
  • Code generation — assigns sensible account numbers when QuickBooks did not ship them (1000s for cash, 4000s for income, etc.)
  • Idempotent re-import — re-running the wizard skips existing records by default; tick "Update existing" to overwrite
  • Country and state lookup — matches against Odoo's res.country and res.country.state automatically
  • Payment terms matching — looks up "Net 30", "Net 15", "Due on receipt" against existing Odoo payment terms by name
  • Accounting-style negatives — handles "(125.00)" in price columns

Data privacy

All processing happens inside your Odoo instance. The module reads CSV files you upload yourself and writes the resulting records to your own database. No data is sent to any external service. The module makes no outbound network calls.
